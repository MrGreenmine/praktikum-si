# Практикум по Си — переработанный сайт

Полная переработка сайта курса «Основы программирования и алгоритмизация»
(кафедра систем управления и ИТ, строительство ВГТУ).

Оригинал: <https://sites.google.com/view/course-of-study1-c/главная>

Репозиторий содержит **и готовый сайт, и все исходники**, из которых он
собран: выгруженный контент оригинала, скрипты выгрузки/сборки, оформление и
памятку по переносу правок обратно в Google Sites.

Что сделано:

* **нумерация приведена к рабочему плану** — «Работа N» теперь означает ровно ту
  лабораторную, которая стоит N-й в плане на осень 2026;
* **меню пересобрано** — разделы идут в логическом порядке, внутри «Практика»
  работы выстроены по неделям, а не в случайном порядке создания страниц;
* **битая markdown-таблица рабочего плана** заменена настоящей HTML-таблицей;
* **добавлены** тёмная тема, поиск по всему сайту, оглавление страницы,
  копирование кода, адаптивная вёрстка и версия для печати.

Контент взят **по факту** с оригинального сайта — ничего не выдумано.

Откройте `site/index.html` в браузере — всё работает и без интернета, и без

## Как пересобрать

Сборка идёт **без интернета** — весь выгруженный контент лежит в `tools/clean/`.

```bash
cd tools
python3 build.py            # пересобрать сайт в ../site
```

Куда собирать, можно указать явно:

```bash
python3 tools/build.py /путь/к/папке
```

Чтобы заново выкачать оригинал (нужен интернет и доступ к сайту):

```bash
cd tools
python3 extract4.py         # перезаписывает tools/clean/ и tools/meta.json
python3 build.py            # и сразу пересобирает site/
```

Требуется только Python 3 (стандартная библиотека), никаких зависимостей.

## Как выложить в интернет

### GitHub Pages (бесплатно)

**Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/site` → Save.**

Через минуту сайт будет доступен на `https://<логин>.github.io/<репозиторий>/`.

### Любой статический хостинг

Загрузите **содержимое папки `site/`** в корень сайта (nginx, Apache, Netlify,
Vercel, GitLab Pages, Timeweb Cloud — что угодно). Сборка не нужна: это готовые
статические файлы.

### Google Sites

См. **[MIGRATION.md](MIGRATION.md)** — памятка, что именно и в каком порядке
поправить в редакторе Google Sites, чтобы сайт остался на прежнем адресе.

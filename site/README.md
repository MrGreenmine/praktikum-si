# Практикум по Си — переработанный сайт

Полная переработка сайта курса «Основы программирования и алгоритмизация»
(кафедра систем управления и ИТ, строительство ВГТУ).
Оригинал: <https://sites.google.com/view/course-of-study1-c/главная>

Что сделано:

* **нумерация приведена к рабочему плану** — «Работа N» теперь означает ровно ту
  лабораторную, которая стоит N-й в плане на осень 2026;
* **меню пересобрано** — разделы идут в логическом порядке, внутри «Практика»
  работы выстроены по неделям, а не в случайном порядке создания страниц;
* **битая markdown-таблица рабочего плана** заменена настоящей HTML-таблицей;
* **добавлены** тёмная тема, поиск по всему сайту, оглавление страницы,
  копирование кода, адаптивная вёрстка и версия для печати.

Контент взят **по факту** с оригинального сайта — ничего не выдумано.

## Как посмотреть

Откройте `index.html` в браузере — всё работает и без интернета, и без сервера
(поиск подгружает локальный `assets/search-index.js`).

## Как выложить в интернет

### Вариант 1 — GitHub Pages (бесплатно)

Репозиторий уже содержит всё: исходники в `tools/`, готовый сайт в `site/`.
Осталось только включить Pages:

**Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/site` → Save.**

Через минуту сайт будет доступен на `https://<ваш-логин>.github.io/<repo>/`.

### Вариант 2 — любой статический хостинг

Загрузите **содержимое папки `site/`** в корень сайта (nginx, Apache, Netlify,
Vercel, GitLab Pages, Timeweb Cloud — что угодно). Сборка не нужна: это готовые
статические файлы.

### Вариант 3 — положить в Google Sites

См. отдельный файл **[MIGRATION.md](MIGRATION.md)** — там памятка, что именно
и в каком порядке поправить в редакторе Google Sites.

## Как пересобрать из оригинала

В репозитории всё лежит в папке `tools/`:

| Файл | Назначение |
|---|---|
| `tools/extract4.py` | скачивает 46 страниц Google Sites и превращает их в чистый HTML (`tools/clean/*.html`, `tools/meta.json`) |
| `tools/codefmt.py` | находит абзацы с исходным кодом и собирает из них блоки `<pre><code>` |
| `tools/build.py` | собирает готовый сайт в папку `site/` |
| `tools/assets/style.css`, `tools/assets/app.js` | оформление и скрипты (копируются в сборку) |
| `tools/docs/` | эта инструкция и `MIGRATION.md` (копируются в сборку) |
| `tools/clean/` | уже выгруженный контент оригинала — можно пересобрать без интернета |

```bash
cd tools
python3 extract4.py     # выкачать и почистить оригинал (нужен интернет)
python3 build.py        # пересобрать сайт в ../site
```

Сборка идёт **без интернета** — весь выгруженный контент лежит в `tools/clean/`.
Куда собирать, можно указать явно:

```bash
python3 tools/build.py /путь/к/папке
```

Содержание пояснительной записки

PDFКП содержание.pdf

Все должно быть отражено в Пояснительной записке. Файл называть КП_группа_Фамилия (например КП_бИСТ211_Петров.doc)

Перед отправкой Проверьте!

  1. Введение содержит цели и задачи ВАШЕГО проекта

  2. Раздел 1 не менее 3 страниц и содержит

  • Обоснование выбора структур данных для БД\массивов и их возможных значений для полей головоломки

  • Контрольный пример заполненной БД \исходное и результирующее поле головоломки с описанием правил игры

  • Перечень выполняемых программой операций, соответствующих возможным пунктам меню программы и обоснование решения по их реализации

И НЕ СОДЕРЖИТ скринов готовой программы и фрагментов кода

  1. Раздел 2 содержит описание всех собственных функций со сложным алгоритмом (ветвления и циклы) виде

"Функция void *qsort(void *base, size_t num, size_t size, int (*compare) (const void *, const void *)) сортирует массив, на который указывает параметр base, используя модифицированный алгоритм быстрой сортировки, представленный на рис. 1. Параметр num задает число элементов массива, параметр size задает размер в байтах каждого элемента. Функция, на которую указывает параметр compare, сравнивает элементы массива с ключом. Функция возвращает указатель на отсортированный таким образом, что наименьший адрес соответствует наименьшему элементу ."

  1. Раздел 1 и Раздел 2 ОТСУТСТВУЮТ ФРАГМЕНТЫ КОДА ПРОГРАММЫ и языковые конструкции

  2. Блок-схемы алгоритмов НАРИСОВАНЫ на белом фоне с черными буквами. В блок-схемах не должно быть языковых конструкций, так как блок-схема алгоритма универсальна и может быть реализована на любом языке программирования. Только имена переменных и операции, последовательность и управление отражается видами блоков. Что не удается отразить, пишется в комментариях. Блок ввода имеет одни вход и один выход, а блок решение один вход и два выхода.

  3. Заключение содержит перечень реализованных возможностей программы + ссылку на код, размещенный на github

  4. Список использованных источников содержит не менее 13 наименований

  5. Приложение содержит код программы с необходимыми комментариями на белом фоне.

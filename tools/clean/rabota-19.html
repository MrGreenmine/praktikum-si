Задания и указания по их выполнению

Задание 1. Напишите программу, которая создает новый файл number.txt в текущей папке и записывает в него произвольную цифру и закрывает файл.

Результатом работы программы является создание файла в текущем каталоге т.е. там, где находится и код программы

Воспользуйтесь меню Файл для открытия созданного файла в IDE

А) Убедитесь, что программа работает, открыв файл number.txt из текущей workspace.

Б) Измените параметр функции fopen() так, чтобы при следующем выполнении программы число 12,56 добавлялось в файл.

В) Добейтесь, чтобы каждое новое число записывалось в файл с новой строки.

Задание 2. Разработайте программу, которая записывает в файл temp.txt, содержащих результат табулирования функции (работа 8 зад.2) вводом из stdin интервала и шага табуляции

Предусмотрите возможность выбора пользователем действий - 1) запись в новый файл 2) дозапись в существующий

Задание 3. Разработайте программу, которая записывает в файл поля структуры задания 3 работы 18

Пример. Функция записи в файл массива структур типа kinoseans

Результат записи в файл

При выборе формата вывода данных следует помнить, что функция scanf будет читать строку (%s) до первого пробела, следовательно

1) строка записи по каждому спецификатору %s не должна содержать пробелы (например, "Домик_в_лесу")

2) после спецификатора %s должен следовать разделитель (пробел, перевод строки, табуляция) , иначе при чтении следующий символ считается вместе со строкой, а в буфере останется не интерпретируемый набор символов.

3) в конце каждой записи должен быть конец строки ('\n') или собственный разделитель

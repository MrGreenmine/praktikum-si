Инструменты разработки

В мире разработки давно есть много удобных инструментов, помимо текстового редактора и компилятора, которые позволяют легко и удобно создавать программы.

В первую очередь, это IDE (Integrated development environment- интегрированная среда разработки) - комплекс программных средств, используемый программистами для создания программного обеспечения. Как правило, такие программные системы объединяют под общим пользовательским интерфейсом - Текстовый редактор, Транслятор (компилятор и/или интерпретатор), Средства автоматизации сборки файлов программного проекта, Отладчик. Наиболее популярные среды разработки IntelliJ IDEA, NetBeans, Eclipse, Qt Creator, Geany, Embarcadero RAD Studio, Code::Blocks, Microsoft Visual Studio, обычно предназначены для нескольких языков.

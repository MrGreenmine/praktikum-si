Работа 15. Работа с одномерными массивами

прежняя нумерация: Работа 11неделя 11

Цель работы - получение навыков создания и заполнения значениями массивов

PDF11_Массивы начало.pdf

Задания и указания по их выполнению

Задание 1. Реализуйте программу работы с массивом по следующему плану:

1. Объявите массив вещественных чисел из 10 элементов:

float A[10];

2. Напишите программу заполнения массива с консоли.

for(int i=0; i<10; i++)
{
printf("a[%d] = ", i+1);
scanf("%f", &temp);
A[i]=temp;
}

3. Выполните заданное преобразование над элементами массива (ПО ВАРИАНТУ):

    1. удвоить значение каждого элемента массива;

    2. увеличить на 1 значение каждого второго элемента массива;

    3. обнулить отрицательные элементы массива;

    4. возвести в квадрат значение каждого элемента массива;

    5. уменьшить в 10 раз значение каждого элемента массива;

    6. изменить знак каждого элемента массива;

    7. уменьшить на константу значение каждого элемента массива;

    8. отбросить дробную часть у всех элементов массива;

    9. установить в 1 значения всех четных элементов массива;

    10. округлить в большую сторону все элементы массива;

    11. к каждому элементу массива прибавить значение последнего элемента;

    12. заменить нулевые значения элементов массива их порядковым номером.

4. Результаты вывести на экран в виде таблицы, в первом столбце которой указать номер элемента, во втором – исходный элемент, в третьем – преобразованный.

| индекс | исходное значение | новое значение

5. Определите количество элементов массива через директиву препроцессора

#define N 10

6. Вычислите среднее арифметическое элементов массива.

Задание 2. Сгенерируйте массив из 100 вещественных значений, вычисленных по заданной функции и интервалу зад.2 работы 8,

Вычислите среднее значение всех положительных элементов массива.

Результаты вывести в виде строки, содержащей:

имя массива;

накопленное значение (для положительных и отрицательных элементов считать отдельно);

число положительных и отрицательных элементов;

вычисленное среднее.

Реализуйте вычисление значений для каждого элемента массива в виде собственной функции.
